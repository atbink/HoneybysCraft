# 🧸 HONEYBYS.CRAFT

> **"Your Imagination, Made Huggable."**  
> Studio kerajinan boneka handmade premium & kustom karakter — mengubah imajinasi, karakter original (OC), anime, idol, hingga anabul menjadi karya fisik yang nyata dan hangat dipeluk.

---

## ✨ Fitur & Keunggulan Studio

- 🤎 **No Minimum Order** — Pesan satuan tanpa batasan kuota pabrik.
- 🧸 **100% Custom Made** — Dibuat dari nol berdasarkan referensi sketsa, ilustrasi, atau foto.
- 🎨 **Personalized Design** — Karakter, outfit, warna, hingga detail ekspresi wajah bordir manual.
- 📦 **Flexible Quantity** — Menerima pesanan satuan, small batch komunitas, hingga kebutuhan maskot brand.
- 🪡 **Interactive Before & After Slider** — Perbandingan presisi dari sketsa 2D ke boneka fisik 3D.
- 💬 **WhatsApp Direct Integration** — Semua CTA terhubung langsung ke WhatsApp (`0858-7776-6376`) dengan auto-text kontekstual.
- 🪄 **Dynamic Scroll Animations** — Pengalaman visual interaktif berbasis *Framer Motion* dengan estetika artisanal editorial.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Motion & Interaction**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) + Handcrafted Studio SVGs

## 🚀 Menjalankan Proyek Secara Lokal

1. **Clone repositori**:
   ```bash
   git clone https://github.com/atbink/HoneybysCraft.git
   cd HoneybysCraft
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka `http://localhost:5173` di browser Anda.

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
